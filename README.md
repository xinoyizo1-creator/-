# 深藍群島｜海洋生態探索網站

以 HTML、CSS 與原生 JavaScript 製作的響應式互動網站，無需安裝套件，可直接開啟 `index.html`，也可部署為 Vercel 靜態網站。

## 網站功能

- 五座可點選的生態島：珊瑚花園、藍潮海灣、極光冰原、紅樹林秘境、月光深海
- 每座島都有專屬動物清單；點選動物可閱讀棲地、食物、生活習性與保育觀察
- 角色可用桌面方向鍵／WASD、畫面方向鍵或手機滑動畫面移動
- 會員登入、聊天室與海洋小舖的互動介面
- 適配 iPhone 與桌面瀏覽器

## 專案檔案

- `index.html`：網站內容與介面結構
- `styles.css`：水族館場景、原始視覺樣式與響應式排版
- `script.js`：島嶼動物資料、詳細介紹及互動功能

會員、即時聊天與購物目前是前端示意介面，尚未連接資料庫、會員服務或金流。畫面採 CSS 分層呈現 3D 風格，尚未載入 WebGL 模型。
